Kendra

The Sovereign AI Arachnid

Kendra is a six-legged robot companion who listens, talks, remembers people and moves, using models that run on her own computer. Virtual Kendra runs on an Intel iMac with a Webots twin today. The Raspberry Pi 5 robot stays locked until five hardware gates are verified on the real machine.

Voice

What happens when someone says "Kendra"

Every step runs on the machine Kendra lives on. The services pass newline-delimited JSON over Unix sockets, and a movement command skips the language model entirely.

Safety

Why the legs stop when the heartbeat does

Kendra treats the language model's output as untrusted input. Five layers sit between the model and the motors, and each lower layer can stop the one above it.

Memory and identity

Where memories and faces are stored

What Kendra knows and who she recognizes live in two separate SQLite files. Face vectors stay in the identity store; Kendra Brain only ever sees an opaque person id.

Corrections keep history

A correction writes a new memory and marks the old one superseded, so the earlier version stays in the database.

No surprise downloads

The ONNX embedders load only from local files. The hashing embedder needs no download, which is why the PC profile works on a fresh clone.

Consent is checked in code

The identity store raises a permission error when an enrollment arrives without the consent flag.

Run it

Try Kendra Brain on any computer, or run the full stack on an iMac

The first path needs Python 3.11 and nothing else. Voice, the webcam, Webots and the local models need a real desktop; the scripts target an Intel iMac.

Any computertests + memory
git clone https://github.com/NXTLupo/kendra.git && cd kendra
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]" && pytest -q
# zero-download hashing embedder
python -m kendra --config config/pc.yaml init
python -m kendra --config config/pc.yaml brain search "language model"

python -m kendra --config config/webots.yaml dev start --voice
# then open the desktop app and say "Kendra"
